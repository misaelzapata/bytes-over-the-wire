# Graffiti reference set (para analizar + entradas de "reproducir desde imagen")

Muestra chica y **diversa por estilo/tier**, para (a) estudiar cómo se construye un grafiti real
(formas, **capas**, orden de pintado, colores, drips) y (b) usarse como imágenes de entrada del modo
"reproducir un grafiti por etapas".

> Nota de color: algunas referencias tienen violeta/magenta (p. ej. el contorno del throw-up). Son solo
> **referencia de forma/capa/proceso** — la paleta que el juego EMITE sigue siendo cálida y **sin violeta**.

## Sets más grandes para análisis profundo (no incluidos, por tamaño)
- **17K-Graffiti** — 17.000 grafitis con bounding boxes: https://github.com/visual-ds/17K-Graffiti
- **graffiti-net** — 5.623 fotos organizadas por **15 artistas** (variedad de estilo/mano): https://github.com/rememberlenny/graffiti-net
- **graffiti-dataset** (pavelkraleu) — trae **análisis de color** (clusters RGB/HSV), tipo de herramienta (spray/marker), y máscaras de segmentación: https://github.com/pavelkraleu/graffiti-dataset
- **Graffiti Classification** (Kaggle) — imágenes sacadas de **Google Street View API** (encaja con el modo Street View): https://www.kaggle.com/datasets/pinstripezebra/graffiti-classification
- **Wikimedia Commons — Category:Graffiti** (~1.964 imgs, subcategorías por medio/superficie/sujeto): https://commons.wikimedia.org/wiki/Category:Graffiti
